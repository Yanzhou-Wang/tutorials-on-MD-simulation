# I. README

- `singlePoint-outcars2nep-exyz.sh`: Extracts only the **last frame** from each `OUTCAR` file to construct `dataset.xyz`. This script is ideal for building datasets from VASP **single-point calculations**.

- `traj-outcars2nep-exyz.sh`: Extracts **all frames** from all `OUTCAR` files to construct `dataset.xyz`. It is therefore suitable for trajectories generated by **AIMD, structural relaxation, or cell optimization** calculations.
